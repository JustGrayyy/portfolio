# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Vanilla HTML/CSS/JS with inline SVG 2D character rigging, HTML5 Canvas 60fps particle physics, and Web Audio API synthesized comic sound effects (zero external build steps or libraries).

## Users
Personal portfolio visitors (collaborators, peers, recruiters, anime fans) viewing the creator's under-construction landing page.

## Product Purpose
Deliver an interactive, hand-drawn 2D manga sketchbook under-construction page featuring an Umaru-chan inspired anime chibi character. Visitors can interact by batting/hitting the chibi with high-speed mouse swipes, poking and clicking for squash-and-stretch reactions, triggering Umaru floor-roll tantrums, or dragging and tossing the character across the screen.

## Positioning
Replaces generic 3D tech / construction cliches with a distinct, charming, hand-drawn anime aesthetic that highlights frontend polish, interactive physics craft, and playful personality.
